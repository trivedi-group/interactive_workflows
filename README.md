# Interactive ML workflows for chemometrics
machine learning workflows using widgets 

#Essentials and installs
You will require Orange and/or Knime installed.
You can install this on MacOS, Windows or Linux.

#Background
Understanding of how Python works will be an added advantage.

#Tutorials
Tutorials within each workflow will explain what you input and what happens to your data.
You must remember the limitations of each ML approach you choose. If not, I've highlighted it as a tooltip.
